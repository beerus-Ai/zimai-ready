# ZimAI Ready

**Prepare for the Future of Work.**
Discover where you stand, learn what matters, and become AI Ready in your profession.

ZimAI Ready is an AI workforce readiness, reskilling and certification platform designed for Zimbabwean
employees and employers. Gemini personalises the whole journey:

`ASSESS → ANALYSE → RECOMMEND → LEARN → PRACTISE → ASSESS → CERTIFY → CONTINUOUSLY UPSKILL`

## Run locally

```bash
npm install
cp .env.local.example .env.local   # add GEMINI_API_KEY (optional)
npm run dev                         # http://localhost:3000
```

The app works fully **without** a Gemini key: every AI feature has a deterministic built-in engine
("ZimAI engine" badge). With a key, content is generated by Gemini ("Gemini AI" badge).

## Architecture

```
types.ts                 Data models (users, profiles, assessments, modules, progress, certificates, organisations…)
config.ts                Gemini models, certification rules
services/gemini.ts       The only Gemini gateway (JSON/text/chat + fallbacks, model fallback, status)
services/store.tsx       App state (useApp) — write-through to the active backend
services/backend/        Backend interface + localStorage and Firebase (Auth + Firestore) implementations
data/                    Industries, roles, skills taxonomy, learning catalogue, lesson content, demo seed
lib/                     Scoring (readiness & exposure), progress, certification rules, AI context
components/              Design system (ui), brand, layouts
features/                landing · auth · onboarding · readiness · dashboard · learning · tutor ·
                         certification · employer · settings
firestore.rules          Security rules (public certificate verification, private user data, org-owner workforce)
```

### Stages
1. **Foundation & readiness** — landing, demo/auth, 9-question visual assessment, Gemini readiness analysis
   (Personal AI Readiness + Workplace AI Exposure, anchored by a transparent scoring formula), results,
   AI Skills Prescription, career transition analysis.
2. **Learning engine** — personalised path from the prescription, 11 domain pathways, micro-lessons,
   personalised AI examples, adaptive learning, Gemini AI Tutor, practical activities with AI feedback,
   skills map, reassessment.
3. **Certification** — Gemini-generated domain assessment, practical capstone with transparent rubric,
   AI Aware / AI Capable / AI Ready rules, QR-verifiable certificates, public verification, shareable
   AI Skills Profile, continuous readiness.
4. **Employer intelligence** — organisation AI maturity, executive workforce dashboard, skills gaps,
   employer-defined competencies, Domain vs Employer AI Ready certification, employee management,
   Gemini Workforce Advisor.
